LTV Logo Playground

Every animation from ltv-logo-js, rendered live.

Usage

Web component

<ltv-logo> as a loading indicator 
<script src="https://unpkg.com/ltv-logo-js"></script>
<ltv-logo size="5" animation="intro"></ltv-logo>

Vanilla JS

import { mountLogo } from 'ltv-logo-js';
mountLogo('#app', { size: 3, animation: 'assemble' });

HTML string (SSR)

import { renderLogo, styles } from 'ltv-logo-js';
const html = renderLogo({ size: 3, animation: 'float' });
